# bookchaowalit-hashgen-frontend — Product brief

**Slug:** `bookchaowalit-website/bookchaowalit-hashgen-frontend`
**Status:** local developer utility / portfolio boundary

## Purpose

Hash Generator lets a visitor turn text into SHA-1, SHA-256, SHA-384, or
SHA-512 hexadecimal digests in the browser with the Web Crypto API.

## Audience and scene

Developers checking a checksum while working locally. The useful path is
short: choose an algorithm, paste text, generate, then copy the digest.

## Constraints

- Fully client-side; no API key, account, or server-side storage.
- SHA output is hexadecimal and generated by the browser Web Crypto API.
- This is a portfolio utility, not a security product or multi-tenant SaaS.
